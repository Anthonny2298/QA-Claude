Ejercicios
1.Respuesta correcta: b) El grado en que los procesos están definidos, gestionados y optimizados.
Explicación: La madurez mide qué tan bien establecidos y controlados están los procesos dentro
de una organización.
2.Respuesta correcta: b) Identificar si el proceso puede lograr de forma consistente los resultados
esperados.
Explicación: La capacidad se refiere a la habilidad del proceso para repetir resultados de acuerdo
a lo planeado.
3.Respuesta correcta: b) CMM (Capability Maturity Model)
Explicación: CMM es el modelo que establece niveles claros de madurez organizacional para
procesos de software.
4.Respuesta correcta: c) Establecido
Explicación: Un proceso "establecido" se define, es consistente y está bajo control dentro de la
organización, según ISO/IEC 15504.
5.Respuesta correcta: b) Mejora continua de calidad y eficiencia.
Explicación: Evaluar madurez y capacidad permite identificar áreas de mejora, lo que conduce a
procesos más eficientes y productos de mayor calidad.
